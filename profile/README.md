# 东方之翼 · Eastern Wing

**A spotting group of aviation enthusiasts from China.**
网站： <https://ewpics.com> 

---

## 我们是谁

东方之翼是一个由航空摄影爱好者组成的社群。我们拍飞机，也为"拍好一架飞机"这件事定下标准：每一张提交的作品都由人审阅，按公开的收录准则判断取舍，而不是按热度或算法。

## 我们做什么

我们运营一座航空摄影画廊。摄影师提交作品，审核员依据收录准则复核，入选作品进入画廊、机队与航空公司档案，以及「编辑之选」和「七日内热门」两个栏目。

## 加入我们

社群通过申请加入。请在 [ewpics.com](https://ewpics.com) 提交申请，我们会逐份阅读。
